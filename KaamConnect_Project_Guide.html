🚀 Vision & Challenge Overview

In developing countries like Pakistan, the vast informal service economy—comprising plumbers, electricians, AC technicians, cleaners, and beauticians—operates entirely through unorganized channels like conversational WhatsApp chats, calls, and word-of-mouth. This results in:

  • Inefficient service matching and lost daily wages for blue-collar workers.
  • A lack of automation and difficulty booking reliable help at transparent rates.
  • Poor user experience for clients struggling to find nearby, trusted, and available providers.

KaamConnect is a cutting-edge Agentic AI System that automates the end-to-end lifecycle of a service request. From parsing a natural language query in English, Urdu, or Roman Urdu to finding, ranking, booking, scheduling, and executing follow-ups—all simulated in real-time within an intuitive, premium mobile application.

💡 Key Innovation: Unlike conventional apps with complex form UI, KaamConnect allows users to talk in their natural dialect. It demystifies AI execution by streaming trace logs straight to their screen.

📐 Overall Solution Design & Architecture

Overall Flow Sequence

  1. Input Parsing: The client sends conversational Roman Urdu text over WebSockets to the Node backend.
  2. Agentic Execution: The backend orchestrator starts a step-by-step reasoning cycle across five specialized agents.
  3. WebSocket Telemetry: प्रोसेस execution logs (trace metrics) are streamed back to the client instantly.
  4. State Update: When a provider matches, bookings are written to Firestore, reflecting on the client screen.

🤖 Developed AI Agents

The backend engine features five highly specialized, autonomous agents that manage distinct phases of the lifecycle:

1. Intent Parser Agent

Extracts core details from unstructured Urdu, Roman Urdu, or English queries. Outlines service_type, location, and time_preference.

2. Discovery Agent

Executes coordinate queries around the parsed location using geocoding engines, returning matching local providers within a 5km radius.

3. Matching Agent

Orders candidate providers based on score, physical distance matrices, ratings, and time-slot compatibility, selecting the top provider.

4. Booking Agent

Handles transactional generation, formats local dates in Pakistan Standard Time (PKT), and persists state to Firestore.

5. Follow-Up Agent

Manages background notification reminders (1 hour prior to appointment) and triggers simulated post-completion checklists for quality audits.
